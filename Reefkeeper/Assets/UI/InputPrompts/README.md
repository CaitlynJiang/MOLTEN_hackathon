# Input prompts

Kenney Input Prompts 1.5A, CC0. Source: https://kenney.nl/assets/input-prompts
Original PNGs from the Double export, copied from the user-provided asset pack.
H, O, F1, R and B come from the same original archive's Keyboard & Mouse/Double.
See KENNEY-LICENSE.txt. Source pixels are unchanged.

Desktop and simulator FPS/body mode show keyboard/mouse inputs. Native controller
mode shows left/right Quest Grip glyphs, selected from the actual interacting
hand (or selected simulator hand when idle). XRI Select is bound to GripButton.
The brush releases when Grip is released. Coral retains its existing persistent
hand behavior after release. The simulator still uses G to emulate Grip; this
mapping is documented in the folded controls. No Quest B drop binding is added.

These prompts do not enable or validate Quest hardware support.
